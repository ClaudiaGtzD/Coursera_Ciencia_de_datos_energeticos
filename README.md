
# ⚡ Coursera – Ciencia de Datos Energéticos

## 📌 Contenidos destacados

- **Exploración de datos energéticos** con sensores AMI
- **Análisis visual** mediante gráficos de radar, ejes paralelos, consumo diario, etc.
- **Preparación de datos** para modelado y series temporales
- **Minería de datos** con descubrimiento de patrones e itemsets frecuentes
- **Modelos predictivos**: árboles de decisión, redes neuronales, pronósticos de demanda y generación
- **Series de tiempo**: descomposición, Fourier, horizontes de predicción

## ▶️ Cómo usar

1. Clona este repositorio:
   ```bash
   git clone https://github.com/ClaudiaGtzD/Coursera_Ciencia_de_datos_energeticos.git
   cd Coursera_Ciencia_de_datos_energeticos
   ```

2. Abre los notebooks en Jupyter, Google Colab o tu entorno preferido.

3. Revisa cada módulo de forma secuencial para seguir el flujo del curso.

## 📘 Requisitos

- Python 3.7+
- Recomendado: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`, `tensorflow` o `keras`, `statsmodels`
